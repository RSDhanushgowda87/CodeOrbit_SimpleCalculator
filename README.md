# CodeOrbit_SimpleCalculator
Project title:Simple Calculator
Technologies used:Python 3(built-in input/output functions, exception handling via try/except)
Setup instructions:
1. Ensure Python 3.x is installed on your machine.
2. Add a new file and type or create python script that performs basic arithmetic operations and name the file as calculator.py.
3. open the file calculator.py and copy paste it in puthon or idle and save file and press F5 the result comes.
